Welcome to the Fate/Grand Automata (FGA) wiki!

FGA automates repetitive farming in Fate/Grand Order on Android 7 and later.
It doesn't touch the game itself: it looks at the screen and taps it like you would. No root is needed on phones.

New to FGA? Start with [Getting Started](Getting-Started). If something doesn't work, check [Troubleshooting](Troubleshooting).

## What FGA can do

| Script | What it does |
|---|---|
| [Battle](Battle) | Repeats a quest: picks the support, uses skills and NPs from your command, picks face cards, refills AP |
| [Friend Point Summon](Friend-Point-Summon) | Rolls FP summons, including the daily free summon |
| [Lottery](Lottery) | Spins the event lottery, optionally clearing the Present Box when it fills up |
| [Gift Box](Gift-Box) | Receives EXP cards (embers) from the Present Box |
| [Servant Enhancement](Servant-Enhancement) | Levels a Servant with embers, optionally ascending them |
| [Skill Enhancement](Skill-Enhancement) | Levels a Servant's skills up to target levels |
| [Support Image Maker](Support-Image-Maker) | Saves Servant, CE and friend name images for support selection |

You don't choose the script yourself: when you press the PLAY button, FGA detects which screen you're on and offers the matching script.

## Things we won't support

This app is only meant to automate repetitive farming battles.
We won't add anything that could lead to bot accounts which need no supervision, or that blatantly violates FGO's ToS.

We won't provide support for:
1. Re-rolling scripts
2. Automatically logging in at the reset times
3. Doing the story for you
4. Messing with the game data or network connections
5. Playing with the screen turned OFF or FGO not in the foreground
6. Playing offline
