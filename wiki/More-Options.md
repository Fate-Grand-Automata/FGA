**More options** on the FGA main screen has three tabs: Battle, Storage and Advanced.

## Battle

| Setting | What it does |
|---|---|
| Game Server | The FGO server you play on. **Auto-detect** (default) uses the FGO app that is open. |
| Story Skip | Skips the story automatically. Unstable, use at your own risk. |
| Enable Withdraw | When all Servants are defeated, withdraw and continue farming instead of stopping. |
| Stop on CE GET | Stop when a first-time quest completion reward or a Bond CE drops. Experimental. |
| Stop on first-clear rewards | Stop when you get first-clear rewards. |
| Screenshot Drops | Save a screenshot of the drops after each battle to the `drops` folder. |
| Save unmodified screenshots | Save full-screen screenshots of the drops instead of cropped and rescaled ones. |
| Screenshot Bond | Save a screenshot of bond level-ups to the `bond` folder. Experimental, may miss some. |
| Hide SQ in AP Resources | Hide SQ from the refill options so you don't use it by accident. On by default. |
| Boost Item | For quests that offer boost items: **Disabled** (default), **Skip**, or use item 1, 2 or 3. |
| Skip servant face-card checks | Don't open the Servant details at the start of a battle. Then [Brave Chains, Servant Priority](Card-Priority) and [Shuffle cards](Battle#shuffle-cards) don't work. |
| Treat Support like own Servants | Recognize the support's face cards like your own Servants' instead of by the "Support" icon. Helps with heavily buffed supports, but breaks card priority if the same Servant is in your party twice. |

## Storage

- **Folder:** where FGA keeps support images, drop screenshots, bond screenshots and recordings.
- **Extract Default Support Images:** extract the default [support images](Support-Image-Maker#default-images) again.

## Advanced

| Setting | What it does |
|---|---|
| Fine-tune | Timing, swipe and image matching settings. See [Fine-tune](Fine-tune). |
| Debug mode | Highlight the regions FGA is looking at. Useful for bug reports. |
| Record Screen | Record the script to `record.mp4` in the storage folder. Not available on Android 13 and later, or with root screenshots. |
| Use Root for Screenshots | Take screenshots with root instead of screen capture. For some [emulators](Running-on-Emulators). Restart the service after changing it. |
| Auto-start service | Start the FGA service when you open the app. |
| Game Area Mode | **Default**, **Surface Duo** or **Custom**. See [Game Area detection](Game-Area-detection). |
| Thresholded stage counter detection | An alternative way to detect the wave counter. Try it if your commands are used in the wrong wave. |
| Check for updates | Offer to install new versions from Google Play. On by default. |
