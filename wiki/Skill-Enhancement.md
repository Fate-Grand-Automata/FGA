Levels a Servant's three skills up to the levels you choose, one skill after another. Append skills aren't supported.

## Starting

1. In FGO, go to Skill Enhancement and select the Servant.
2. Press PLAY.

FGA reads the current skill levels and shows them in the dialog.

## Options

For each skill, set the target level next to its current level. Skills left at their current level are skipped.
**All skills** with **Lv. 6**, **Lv. 9** or **Lv. 10** sets every unlocked skill to that level at once. Skills already above it keep their level.

A skill shows **Locked** or **Max level** instead when it can't be enhanced, and **Couldn't read level** when FGA can't read it. Those skills are skipped.

## When it stops

The dialog at the end shows each skill's level before and after, and what happened to it:

- **Insufficient materials:** FGA moves on to the next skill.
- **Insufficient QP:** the script stops, since the other skills can't be enhanced either.
- **Didn't reach Lv. X:** the script stopped before getting to this skill.

The script also stops when the skill level stops going up, or when the Servant gets deselected.
